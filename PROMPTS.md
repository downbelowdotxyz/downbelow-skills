# Things you can say

Copy, paste, and change the bits in brackets. You don't need exact wording; these just show what works well.

## Getting started

```text
Use the start skill. I want to make a game.
```
```text
Use game-idea. I like [games you love, e.g. Celeste and Stardew Valley] but I have no idea what to make.
```
```text
Use game-idea. My idea: [a top-down game where you're a ghost haunting a house]. Help me make it small enough to finish.
```
```text
Use pick-engine and set up the project.
```

## Building

```text
Build the next thing.
```
```text
Add [a double jump]. Keep it small and let me try it.
```
```text
The [jump] feels [too floaty]. Make it [snappier] and tell me which number you changed.
```
```text
Make it feel better: add screen shake and a sound when [the player gets hit].
```
```text
Add a title screen and a game over screen with "play again".
```
```text
Use add-art. Replace the placeholder squares with free pixel art that fits the game, and add credits.
```

## When something's wrong

```text
Use fix-bug. When I [jump onto the moving platform] I [fall through it]. I expected [to ride on it].
```
```text
It's a blank screen. Here's the console error: [paste red text]
```
```text
It worked an hour ago. What changed since the last checkpoint?
```
```text
Go back to the last checkpoint.
```

## Checking and understanding

```text
Use playtest and play through the whole game once. Tell me what's broken or confusing.
```
```text
Explain how [the enemy movement] works in plain words. Which file and which numbers would I change?
```
```text
What's in PROGRESS.md? Where did we leave off?
```

## Sharing

```text
Use ship-it. I want to put this on itch.io for my friends.
```
