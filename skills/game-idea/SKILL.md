# Game Idea → One-Page Brief

A few back-and-forth messages, not an interview. The result is `game-brief.md` in the project root, written from [brief-template.md](references/brief-template.md). If `game-brief.md` already exists, read it and improve it instead of starting over.

## 1. Pick the concept

From whatever they gave you (a word, a genre, a game they love, or nothing), offer **3 one-line concepts**. Make each one a verb plus a twist, small enough to build: "Dodge falling meteors while your ship slowly shrinks", "Grow a garden that only blooms at night". Mix one safe pick, one weird pick, and one close to what they said. They pick one or combine them. This is the one creative question every run asks.

If they bring a huge idea (open world, MMO, a full RPG), say it's a great long-term goal and help them find the **smallest game inside it**: one mechanic, one level, one enemy type. That small game becomes version one.

## 2. Fill the brief together

Fill several fields per message. Suggest a value for each and let them change it:

- **Working title**
- **Pitch**: one excited sentence.
- **Core loop**: the 2–4 things the player does over and over.
- **Win / lose**: how a round ends. Even a cozy game needs "a session feels done when…".
- **MVP**: the short list of things that must exist for it to be *this* game. Each item becomes one build step. **Five items or fewer for a first game.** If it's longer, say so, suggest which to cut (the ones the core loop works without), and move them to Out of scope.
- **Out of scope**: what we're deliberately not building yet. This list saves the project.
- **Build order**: the MVP items in order, with the riskiest or most fun-defining one first. Prove it's fun before making it pretty.
- **Look & sound**: one line, such as "chunky pixel art, chiptune".
- **Closest real game**: one game it resembles and the small slice of it we keep.

Things to push back on gently in a first game: online multiplayer, saving progress, procedural worlds, story with branching dialogue, more than one level. Put them in Out of scope as "later".

## 3. Show it, then write it

Show the filled brief. Ask: "Want me to save this as `game-brief.md`?" Write only on a clear yes. If they want a change, make it and show the changed lines.

## 4. Next step

- No engine set up yet → `pick-engine`.
- Project already set up → `build-next`, starting with build order item 1.

Finish with one line: the pitch, the number of MVP items, and the next step.
