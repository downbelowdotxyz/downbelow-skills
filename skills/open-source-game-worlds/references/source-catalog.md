# Source catalog and discovery routes

Discovery snapshot: 2026-11-01. Primary pages below were consulted where noted; no individual download has been approved by this catalog. Check each selected file/release using [license-verification.md](license-verification.md). Availability and terms can change. Repository badges, this table, and search snippets are insufficient license evidence.

## Restricted or conflicting leads

[Quaternius](https://quaternius.com/) offers modular environment kits. Its [FAQ](https://quaternius.com/faq.html) states CC0, while its [QAL license page](https://quaternius.com/license.html), dated 2026-08-28, restricts standalone asset redistribution. Treat this as conflicting evidence, not a blanket CC0 catalog. Determine the exact pack/release grant and acquisition evidence. A demonstrably CC0 historical version needs its own record. A QAL-only download belongs among restricted alternatives, not verified open-content packs. Do not assume 'usable in a game' permits a public source repository or downloadable template.

## Find additional candidates

Search combinations of environment type, dimensionality, editable format, and license. Examples: `isometric village tileset CC0 original creator`, `modular forest glTF source license`, or `open source racing track licenses.txt`. For repositories inspect releases, actual asset directories, Git LFS/submodules, source files, last substantive updates, engine version, dependency manifests, and file-specific licenses. Popularity is not provenance.

For community maps and asset marketplaces, locate the original author, exact downloadable version, and grant. 'Fan recreation', ripped commercial maps, and screenshots of a popular game are not evidence of reusable rights. When complete worlds are unsuitable, compose verified components instead.
