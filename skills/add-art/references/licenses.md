# Licenses in plain words

"Free to download" is not "free to use". Every asset you didn't make comes with a license; read it on the asset's own page, save the license file that came with it, and write it in `CREDITS.md`.

| License | What you can do | What you must do | Watch out |
|---|---|---|---|
| **CC0 / Public domain** | Anything, including selling the game | Nothing (credit is still nice) | Logos and brands shown in a CC0 image aren't covered. |
| **CC-BY** | Anything, including selling | **Credit the author** in the game or on its page | Credit is part of the license, not a courtesy. |
| **CC-BY-SA** | Use and change it | Credit, and share **your changed version of the asset** under the same license | Usually fine for unchanged art; ask before editing it into your own art style. |
| **CC-BY-NC** (any "NC") | Use it only if nobody pays | Credit | **Not allowed in a game you sell**, and risky with ads or donations. Avoid unless the game will always be a free hobby project. |
| **CC-BY-ND** (any "ND") | Use unchanged | Credit | You can't recolor, crop into a sheet, or edit it. |
| **OFL** (fonts) | Use in any game | Keep the license with the font if you ship the font file | Don't sell the font by itself. |
| **MIT / Apache / BSD** (usually code) | Anything | Keep the license notice | Easy. |
| **GPL / LGPL** (usually code) | Use it | GPL can require **your whole game's code** to be open source under GPL | Ask before adding GPL code to a game they might sell closed-source. |
| **Custom / "free for personal use" / "royalty free"** | Read it | Read it | These differ a lot. If it's unclear, pick something else. |
| **No license stated** | **Nothing**, legally | — | Assume it's not allowed. |

## Things that are never OK

- Art, music, characters, or names from existing games, movies, or brands (Mario, Pokémon, Minecraft textures, sprites ripped from a game), even in a free fan game. Game mechanics can't be owned; names, art, and music can.
- "I found it on Google Images", Pinterest, or a wallpaper site.
- Fonts copied from a computer's system fonts folder, unless the font's license allows embedding.

## When a license changes

Creators can change terms for new versions (Quaternius, for example, added a separate license page in 2026 next to older CC0 statements). Record the date you downloaded it and keep the license file you received. Licenses for that copy are what count, and the record is your proof.
